# Reproducibility and provenance

The original experimental record is `archive/claps.py`. It was exported from a Colab notebook with multiple independent cells. Source ranges and their extracted filenames are declared in `tools/extract_experiments.py`; the tool compares the archival SHA-256 before writing. The code within each experiment is copied byte for byte. The markdown cell delimiter is omitted, which allows the appendix scripts' `from __future__` imports to appear in their valid position.

The package in `src/claps/` exposes the reusable weighted Laplace covariance, training-only prior selection from pre-fitted outputs, epistemic quadratic form, finite-sample quantile, calibration, and prediction interval calculation. It is separate from the original benchmark scripts. The numerical-equivalence check compares its covariance and conformal intervals against the original real-data experiment implementation with fixed inputs.

The accepted review manuscript contains four main experiments and four appendix studies. `01_weak_support.py` reproduces the high-dimensional mechanism study (Tables 1–2), `02_weighted_geometry.py` the geometry isolation (Table 3 and Table 6), `03_epistemic_regimes.py` the two controlled sweeps (Figure 1, Tables 7–8), and `04_real_data.py` the eight-dataset benchmark (Tables 4–5 and 9). `05_prior_precision.py`, `06_representation_dimension.py`, and `07_variance_floor.py` cover Tables 10, 11, and 12. `08_ood_stress.py` covers Figure 2 and Table 13.

The author ran the original Colab experiments and verified their reported results. This repository reorganization does not repeat the full neural runs: the eight scripts are byte-for-byte extracts of the experiment cells, and the new reusable CLAPS calculations were compared with the original real-data functions on fixed inputs. PyTorch is unavailable in this packaging environment, so no independent end-to-end reproduction claim is made here. Dataset URLs, hardware-dependent numerical behavior, elapsed training time, and the exact versions of the original Colab environment have not been independently checked during packaging. Readers can run each script to reproduce the reported experiments.
